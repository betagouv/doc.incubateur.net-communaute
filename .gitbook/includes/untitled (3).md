<summary>Le code de confirmation Proconnect est envoyé sur mon email mais j'ai besoin de Proconnect pour y accéder. Comment faire ? </summary>

ProConnect ne demande pas ce code à chaque connexion. Il peut vous envoyer un **code de confirmation à 10 chiffres** lorsque : - vous créez votre compte, - utilisez un nouveau navigateur - ou avez vidé le cache de votre navigateur. Si vous devez utiliser ProConnect pour ouvrir la messagerie qui reçoit ce code, vous pouvez vous retrouver bloqué.

Pour débloquer la situation, [prenez rendez-vous en visioconférence avec Amel Alili](https://rdv.numerique.gouv.fr/motif/hho8iaZ6/debloquer-l-acces-a-ma-messagerie-code-proconnect). Après vérification de votre identité, un lien de connexion à votre messagerie pourra vous être envoyé. Vous pourrez ainsi consulter le code et terminer votre connexion.

Pour éviter que cette situation se reproduise, nous vous recommandons de [configurer votre messagerie dans un client de messagerie installé sur votre ordinateur](https://doc.incubateur.net/communaute/les-outils-de-la-communaute/emails/emails-suite-numerique#etape-2-ou-un-client-lourd-sur-ordinateur). Vous pourrez alors consulter les codes reçus sans devoir ouvrir votre messagerie via ProConnect.

**Attention :** cette réponse concerne le code de confirmation envoyé par e-mail, et non le code à usage unique lié à la double authentification. Pour en savoir plus, consultez la [FAQ de l’équipe ProConnect sur le code de confirmation à 10 chiffres](https://proconnect.crisp.help/fr/article/comment-regler-les-problematiques-liees-au-code-de-confirmation-a-10-chiffres-jyepuz/).
