# FAQ emails

<details>

<summary>Créer un compte email à un nouveau membre</summary>

Pour obtenir leur email, les nouveaux membres doivent être invités par un membre existant via l'espace-membre puis compléter leur fiche sur l'[espace membre](https://espace-membre.incubateur.net/). Le compte email sera automatiquement créé à la validation.

Le compte email est actif tant que le membre à une mission en cours, il ne faut pas oublier de garder sa fiche de membre à jour.

</details>

<details>

<summary>Recréer un compte email pour un ancien membre</summary>

Un membre de ton équipe doit ajouter ta nouvelle mission sur ta fiche via l'[espace membre](https://espace-membre.incubateur.net/).

</details>

<summary>Je n'ai plus accès à mon mail</summary>

**As-tu dépassé ta date de fin de mission ?**

Les droits d'accès aux ressources beta.gouv.fr (dont l'email fait partie) sont liés à la date de fin de mission sur ta fiche membre. Pour savoir si celle-ci est dépassée, tu peux vérifier dans [l'annuaire](https://beta.gouv.fr/communaute/annuaire) si ta fiche figure dans les membres actifs. Si elle figure dans les alumni, c'est que ta date de fin de mission est dépassée. Voici les instructions :

1. Demande à un membre de ton équipe de prolonger ta fiche membre sur l'[espace membre](https://espace-membre.incubateur.net/)

**J'ai besoin d'aide**

N'hésite pas à demander un coup de main aux personnes de ton équipe, ou d'un ou d'une collègue. Tu peux aussi solliciter l'aide de la communauté sur le canal [Entraide-communauté](https://tchap.gouv.fr/#/room/!FznvyqtGVRlsGHcLVE:agent.dinum.tchap.gouv.fr) sur Tchap.

<summary>Le code de confirmation ProConnect est envoyé sur ma messagerie, mais j’ai besoin de ProConnect pour y accéder. Comment faire ?</summary>

ProConnect ne demande pas ce code à chaque connexion. \
Il peut vous envoyer un **code de confirmation à 10 chiffres** lorsque : \
\- vous créez votre compte, \
\- utilisez un nouveau navigateur \
\- ou avez vidé le cache de votre navigateur. \
Si vous devez utiliser ProConnect pour ouvrir la messagerie qui reçoit ce code, vous pouvez vous retrouver bloqué.

Pour débloquer la situation, [prenez rendez-vous en visioconférence avec Amel Alili](https://rdv.numerique.gouv.fr/motif/hho8iaZ6/debloquer-l-acces-a-ma-messagerie-code-proconnect). \
Après vérification de votre identité, un lien de connexion à votre messagerie pourra vous être envoyé. Vous pourrez ainsi consulter le code et terminer votre connexion.

Pour éviter que cette situation se reproduise, nous vous recommandons de [configurer votre messagerie dans un client de messagerie installé sur votre ordinateur](https://doc.incubateur.net/communaute/les-outils-de-la-communaute/emails/emails-suite-numerique#etape-2-ou-un-client-lourd-sur-ordinateur). Vous pourrez alors consulter les codes reçus sans devoir ouvrir votre messagerie via ProConnect.

**Attention :** cette réponse concerne le code de confirmation envoyé par e-mail, et non le code à usage unique lié à la double authentification. \
Pour en savoir plus, consultez la [FAQ de l’équipe ProConnect sur le code de confirmation à 10 chiffres](https://proconnect.crisp.help/fr/article/comment-regler-les-problematiques-liees-au-code-de-confirmation-a-10-chiffres-jyepuz/).

</details>
